# ☁ Cloud Data Redundancy Removal System

## CodeAlpha Cloud Computing Internship Project

### Project Description

This project detects duplicate records before storing them in MongoDB Atlas.

It prevents redundant cloud data and validates each new record.

---

## Features

- Cloud Database (MongoDB Atlas)
- Duplicate Detection
- Search Records
- Edit Records
- Delete Records
- Export CSV
- Dashboard Statistics
- Bootstrap Responsive UI
- Flask Backend

---

## Technology

- Python
- Flask
- MongoDB Atlas
- Bootstrap
- HTML
- CSS
- JavaScript

---

## Installation

```bash

```
